所有测试都可以通过以下命令运行：

```bash

npm test

# 运行特定测试文件

npm test -- --testPathPattern="tls.test.ts"
npm test -- --testPathPattern="ApiResponseBuilder.test.ts"

# 运行覆盖率报告
npm test -- --coverage
```
